# MUICT Club Hub

Build a web-based MUICT Club Registration System. It should let (a) a user view a list of available clubs including AI, Dev, IoT, Cyber, Badminton, Table Tennis, Japanese Society, Board Game, Media and Entertainment, and Speakers.
